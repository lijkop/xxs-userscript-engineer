# 小红书评论批量复制

> 版本：1.1.2 · 作者：小小薯（XXS） · 反馈：[Telegram 频道](https://t.me/zzyyffxx)

## 简介

悬浮球一键提取当前笔记的评论并复制到剪贴板，自动滚动加载完整评论。

## 功能

- 一键提取评论内容并复制到剪贴板
- 自动滚动加载，把折叠的评论一起翻出来
- 悬浮球隐藏式设计，不遮挡内容
- 完成后通过系统通知提示结果

## 使用方法

1. 安装后打开小红书笔记详情页或搜索结果页
2. 点击页面上的悬浮球，脚本会自动滚动加载并提取评论
3. 提取完成后评论已在剪贴板中，可直接粘贴

## 配置说明

无需配置。脚本不提供设置面板，行为固定。
