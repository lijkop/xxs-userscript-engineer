# 小红书评论批量复制

> 版本：1.2.0 · 作者：小小薯（XXS） · 反馈：[Telegram 频道](https://t.me/zzyyffxx)

## 简介

一键提取小红书笔记评论到剪贴板，包含用户名、点赞数、回复数与跟评（楼中楼），支持自动展开折叠的跟评并向下滚动采集。

## 功能

**采集内容**

- 用户名、评论正文、评论附图
- 点赞数与回复数（0 赞时页面显示的是「赞」字，脚本按 0 处理）
- 时间与地区、置顶标记
- 跟评（楼中楼）：自动点击「展开 N 条回复」，并保留与父评论的层级关系

**采集方式**

- 自动滚动：定位**评论区自身的滚动容器**（不是 window，小红书评论区是独立滚动区）
- 动态收集：MutationObserver 持续跟踪新加载的评论，手动滚动也不会漏
- 结束判定：滚到底且连续 6 轮没有新增内容时自动停止
- 进度显示：面板实时展示 根评论 / 跟评 / 合计，以及相对页面总数的进度条

**导出**

- 复制 Markdown：按「根评论 + 缩进跟评」的层级输出，适合存档与阅读
- 复制纯文本：TSV 表格格式，可直接粘贴进 Excel / 表格工具
- 复制完成有系统通知提示

**自检**

- 面板内置「自检选择器」：一键输出各选择器的命中数量，页面改版时能立刻定位是哪个选择器失效

## 使用方法

1. 打开小红书笔记详情页（`/explore/*`）或搜索结果页（`/search_result/*`）
2. 点击右下角悬浮球「评论」打开面板
3. 点「开始采集」，脚本会自动展开跟评并向下滚动，直到没有新评论
4. 点「复制 Markdown」或「复制纯文本」，内容即进入剪贴板
5. 只想抓当前可见的评论：不用点开始采集，直接复制即可（页面滚动时脚本会静默收集）

## 配置说明

无需配置。采集结果只保存在内存中，刷新页面即清空；脚本不读写任何本地存储，也没有除剪贴板与系统通知之外的权限。
