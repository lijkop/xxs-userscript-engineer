# 小黑盒收藏夹整理器

> 版本：1.0.0 · 作者：小小薯（XXS） · 反馈：[Telegram 频道](https://t.me/zzyyffxx)

## 简介

批量整理小黑盒收藏夹：逐条打开收藏的帖子，抓取正文、配图、标签和评论（含楼中楼回复），每条存成一个 Markdown 文件，最后打包成一个 ZIP 下载。也可以顺手取消收藏，边整理边清空。

## 功能

- **自动遍历收藏夹**：在「我的收藏」页点「开始整理」，脚本逐条打开帖子、抓取内容、返回列表、继续下一条，收藏列表滚动加载新条目时会自动接着做。
- **正文完整保留**：同时支持两种帖子排版——文章帖按段落/标题/图片/列表/代码块还原结构；图文帖按换行拆段，并把顶部轮播配图一并收进来。正文里的懒加载图片会先滚进视口触发加载，再写入真实图床地址，不会留下空图或页面自身地址。
- **评论与楼中楼**：抓取主楼评论的用户名、等级、点赞数、时间、IP 属地、正文；楼中楼抓取回复人、内容、时间、IP 属地。默认每篇最多 50 条主楼评论、每条主楼最多 10 条回复，可在面板上调整（填 0 表示不限）。超出上限时，导出的 Markdown 会在评论行标注「已截断」并给出页面实际主楼数。
- **一次下载一个 ZIP**：每篇帖子单独一个 `NNN-标题.md`，另附一份 `index.md`（导出时间、条目列表、原始链接），打成 zip 下载。文件名会自动清洗 `\ / : * ? " < > |` 等非法字符。
- **多种导出格式**：除 ZIP 外，也支持合并导出单个 Markdown、JSON（保留完整结构化数据）、CSV（Excel 友好，带 BOM），或一键复制全部 Markdown 到剪贴板。
- **可选自动取消收藏**：勾选后，每抓完一条就点掉详情页的五角星取消收藏，再前往下一条。取消失败会在记录上留标记并继续。
- **断点续跑**：进度与已抓数据存在脚本存储里，浏览器刷新、误关标签页后重新打开收藏页，面板会提示已有多少条历史记录，可以继续整理或直接导出。
- **可拖动面板**：左上角浮层面板，可收起成右下角胶囊，`Alt+X` 唤出 / 收起，`Esc` 暂停。

## 使用方法

1. 安装脚本后，打开小黑盒网页版的「我的收藏」页面：`https://xiaoheihe.cn/app/user/favour/content`
2. 左上角出现「小黑盒收藏夹整理器」面板，按需调整三个复选框和两个数字上限
3. 点「开始整理」，脚本会自动逐条打开、抓取、返回、继续
4. 全部跑完后点「下载 ZIP（每篇一个 MD）」，浏览器会下载一个按时间命名的 zip 包，解压后每个帖子一个 Markdown 文件
5. 中途想停就点「暂停」或按 `Esc`；「清空数据」会丢弃已抓到的记录

> 如果勾选了「全部完成后自动打包 zip」，跑完会自动触发下载，不用再手动点。

## 配置说明

面板上的开关与数字会即时存进脚本存储，存储键为 `hb_favour_organizer_v1`（一个对象，含 `opts`、`records`、`failed`、`running` 等字段）。

| 配置项 | 存储字段 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 整理完取消收藏 | `opts.removeFav` | 开 | 每抓完一条就取消该帖的收藏 |
| 每条自动复制到剪贴板 | `opts.copyEach` | 关 | 每抓完一条把该条 Markdown 复制到剪贴板 |
| 全部完成后自动打包 zip | `opts.autoZip` | 关 | 全部跑完后自动下载 zip |
| 每篇最多评论 | `opts.maxComments` | 50 | 每篇最多采集多少条主楼评论，`0` = 不限 |
| 每条最多回复 | `opts.maxReplies` | 10 | 每条主楼最多保留多少条楼中楼回复，`0` = 不限 |
| 操作间隔下限 | `opts.minDelay` | 700 | 毫秒，两次操作之间随机等待的下限 |
| 操作间隔上限 | `opts.maxDelay` | 1500 | 毫秒，两次操作之间随机等待的上限 |
