# 小黑盒内容净化器

> 版本：4.2.1 · 作者：小小薯（XXS） · 反馈：[Telegram 频道](https://t.me/zzyyffxx)

## 简介

在小黑盒社区信息流中按关键词、分区、互动数据过滤帖子，净化评论区，并支持一边浏览一边把评论区收进剪贴板。

## 功能

**帖子过滤**

- 标题 / 正文关键词匹配，命中即处理
- 按分区过滤（如「盒友杂谈」）
- 可屏蔽 0 评论、0 点赞的帖子

**评论区净化**

- 过滤「插眼」等无意义回复及自定义关键词
- 过滤纯表情水评
- 支持楼中楼子评论

**评论区导出**

- **手动模式**：点「开始复制」后自己向下滑动评论区，脚本实时收集；点「暂停」停止，可反复切换
- 滚动过程中自动点击新出现的「全部 N 条回复」，把折叠的楼中楼一起收进来
- 导出内容：用户名、点赞数、等级、作者标记、置顶标记、评论正文、回复内容
- 表情转为 `[表情名]` 文本，避免导出后内容缺失
- 按需求**不导出**发布时间与 IP 属地
- 以评论自身的 `data-comment-id` 去重，反复滚动不会重复

**处理方式**

- 隐藏方式可选：直接移除，或淡出占位（保留位置提示）
- 处理后写入标记，避免重复处理

## 使用方法

1. 安装后打开小黑盒社区页面（`/app/bbs/*`）
2. 点右下角盾牌图标，或用油猴菜单「⚙️ 净化设置」打开面板
3. 面板**最上方**就是「评论区导出」：
   - 点「**开始复制**」→ 按钮变成「暂停」，此后你自己向下滑动评论区，脚本会实时收集并展开楼中楼
   - 滑完了点「**暂停**」（可反复开始 / 暂停，中途也能直接复制）
   - 点「**复制结果**」→ 采集到的评论以 Markdown 进入剪贴板
4. 想要纯净化功能，下面的分区过滤 / 帖子过滤 / 评论区过滤三个区块照旧

## 配置说明

- 净化规则的存储键：`hb_ultimate_config_v4_1`
- 导出功能**不写任何存储**，采集结果只存在内存里，刷新页面即清空
- 面板内可维护：帖子关键词、分区关键词、评论关键词、0 赞 / 0 评开关、纯表情过滤、隐藏方式
