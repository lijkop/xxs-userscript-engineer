# 小黑盒内容净化器

> 版本：4.2.0 · 作者：小小薯（XXS） · 反馈：[Telegram 频道](https://t.me/zzyyffxx)

## 简介

在小黑盒社区信息流中按关键词、分区、互动数据过滤帖子，净化评论区，并支持一键把评论区导出为 Markdown。

## 功能

**帖子过滤**

- 标题 / 正文关键词匹配，命中即处理
- 按分区过滤（如「盒友杂谈」）
- 可屏蔽 0 评论、0 点赞的帖子

**评论区净化**

- 过滤「插眼」等无意义回复及自定义关键词
- 过滤纯表情水评
- 支持楼中楼子评论

**评论区导出**

- 一键采集当前帖子的评论并复制为 Markdown
- 自动点击「全部 N 条回复」，展开被折叠的楼中楼
- 自动向下滚动加载更多评论，连续 4 轮无新增时自动停止
- 导出内容：用户名、点赞数、等级、作者标记、置顶标记、评论正文、回复内容
- 表情会转成 `[表情名]` 文本，避免导出后内容缺失
- 按需求**不导出**发布时间与 IP 属地

**处理方式**

- 隐藏方式可选：直接移除，或淡出占位（保留位置提示）
- 处理后写入标记，避免重复处理

## 使用方法

1. 安装后打开小黑盒社区页面（`/app/bbs/*`）
2. 点右下角盾牌图标，或用油猴菜单「⚙️ 净化设置」打开面板
3. 面板上半部分是净化规则，最下面的「评论区导出」有两个按钮：
   - **采集并复制**：自动展开楼中楼 + 向下滚动加载，结束后把 Markdown 复制到剪贴板；采集中再点一次可中途停止
   - **直接复制**：只复制当前页面上已经加载出来的评论，不滚动
4. 粘贴到笔记或编辑器即可

## 配置说明

- 净化规则的存储键：`hb_ultimate_config_v4_1`
- 导出功能**不写任何存储**，采集结果只存在内存里，刷新页面即清空
- 面板内可维护：帖子关键词、分区关键词、评论关键词、0 赞 / 0 评开关、纯表情过滤、隐藏方式
