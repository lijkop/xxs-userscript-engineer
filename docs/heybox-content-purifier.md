# 小黑盒内容净化器

> 版本：4.1.2 · 作者：小小薯（XXS） · 反馈：[Telegram 频道](https://t.me/zzyyffxx)

## 简介

在小黑盒社区信息流中按关键词、分区、互动数据过滤帖子，并净化评论区，动态加载的内容同样处理。

## 功能

**帖子过滤**
- 标题 / 正文关键词匹配，命中即处理
- 按分区过滤（如「盒友杂谈」）
- 可屏蔽 0 评论、0 点赞的帖子

**评论区净化**
- 过滤「插眼」等无意义回复及自定义关键词
- 过滤纯表情水评
- 支持楼中楼子评论

**处理方式**
- 隐藏方式可选：直接移除，或淡出占位（保留位置提示）
- 处理后写入标记，避免重复处理

## 使用方法

1. 安装后打开小黑盒社区页面（`/app/bbs/*`）
2. 点击油猴菜单中的「⚙️ 净化设置」打开配置面板
3. 在面板里添加关键词（输入后回车确认）、勾选要启用的过滤规则
4. 配置即时生效，并保存在本地

## 配置说明

- 配置存储键：`hb_ultimate_config_v4_1`
- 面板内可维护：帖子关键词、分区关键词、评论关键词、0 赞 / 0 评开关、纯表情过滤、隐藏方式
- 配置保存在本地（Tampermonkey / Violentmonkey 存储），不会上传
