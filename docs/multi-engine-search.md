# 多引擎批量搜索

> 版本：2.1.2 · 作者：小小薯（XXS） · 反馈：[Telegram 频道](https://t.me/zzyyffxx)

## 简介

把当前关键词一次交给多个搜索引擎同时搜索，支持引擎分组、快捷键、悬浮按钮与配置导入导出。

## 功能

- 一键在多个搜索引擎同时打开搜索结果
- 引擎按分类分组管理，常用组合随时调用
- 快捷键可录制（支持 Ctrl / Alt / Shift / Meta 组合），另有油猴菜单与悬浮按钮入口
- 支持拖拽排序、增删引擎、导入导出配置

## 使用方法

1. 安装后任意页面可用（输入框中的内容会作为搜索词）
2. 通过油猴菜单「打开多引擎搜索」直接触发搜索
3. 通过「打开多引擎搜索设置」维护引擎列表、分类与快捷键
4. 搜索结果会用新标签页打开

## 配置说明

- 引擎列表、快捷键、分类等配置保存在本地存储，可导入导出
- 需要打开新标签页，因此申请了 `GM_openInTab` 权限

## 兼容网站

- `*://*/*`（全站脚本：需要在任意页面读取当前关键词并发起搜索）
