# 网页正文一键提取

> 版本：1.0.1 · 作者：小小薯（XXS） · 反馈：[Telegram 频道](https://t.me/zzyyffxx)

## 简介

按快捷键提取并清洗网页正文，复制到剪贴板。保留链接文字、去掉链接地址。

## 功能

- 快捷键触发，一键把正文提取到剪贴板
- 自动清洗：保留链接文字、去除链接 URL
- 可视化快捷键设置面板，支持 Ctrl / Alt / Shift / Meta 组合
- 全站生效：资讯站、博客、文档站均可使用

## 使用方法

1. 安装后任意页面按默认快捷键即可提取正文
2. 想改键位：油猴菜单「⚙️ 修改无感复制快捷键」
3. 提取结果直接进入剪贴板，粘贴即可

## 配置说明

- 配置存储键：`web_text_extractor_config`
- 面板内可设置快捷键组合，配置保存在本地

## 兼容网站

- `*://*/*`（全站脚本：需要在任意页面提取正文）
