# 豆瓣小组关键词屏蔽器

> 版本：1.0.2 · 作者：小小薯（XXS） · 反馈：[Telegram 频道](https://t.me/zzyyffxx)

## 简介

屏蔽豆瓣小组中标签或标题命中关键词的帖子。

## 功能

- 标签与标题双维度匹配
- 命中即隐藏，小组列表更清爽
- MutationObserver 跟踪列表动态加载

## 使用方法

1. 安装后打开豆瓣小组页面
2. 通过脚本面板维护关键词（输入后回车确认）
3. 配置即时生效

## 配置说明

- 关键词保存在本地存储，不上传
- 可随时在面板中增删

## 兼容网站

- `https://douban.com/group/*`
- `https://www.douban.com/group/*`
