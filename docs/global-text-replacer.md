# 全网文本替换器

> 版本：1.4.1 · 作者：小小薯（XXS） · 反馈：[Telegram 频道](https://t.me/zzyyffxx)

## 简介

按自定义规则在全网页面替换文本内容，适配 React / Vue 页面与虚拟列表。

## 功能

- 自定义替换规则，支持多组同时生效
- 适配 React / Vue 与虚拟列表，动态渲染的内容不会被漏掉
- 三重生效时机：首次加载、DOM 动态变更、定时兜底
- 贴边小球入口，面板隐藏不挡内容

## 使用方法

1. 安装后任意页面可见贴边小球
2. 点击小球打开设置面板，添加「原文 → 替换为」规则
3. 规则即时应用，可在面板中随时开关

## 配置说明

- 替换规则保存在本地存储，不上传
- 面板内可增删规则、切换启用状态

## 兼容网站

- `*://*/*`（全站脚本：需要在任意页面替换文本）
