# Xtract

> 版本：1.3.0 · 作者：小小薯（XXS） · 反馈：[Telegram 频道](https://t.me/zzyyffxx)

## 简介

X（Twitter）内容采集工具：抓用户主页时间线上的帖子、单条帖子下的转帖用户与引用推文。边滑边记，暂停后一键复制或导出，适合做资料归档与选题收集。

## 功能

**四种页面，各取所需**

| 页面 | 抓到的内容 |
|---|---|
| `x.com/<用户名>` | 时间线全部帖子，含置顶与转帖（用「上下文」字段区分） |
| `/status/<id>/retweets` | 转帖了这条帖子的**用户**：账号、昵称、简介 |
| `/status/<id>/quotes` | 引用了这条帖子的**推文**：正文、作者、各项计数 |
| `/status/<id>` | 主帖 + 评论区，可一键复制正文 + 评论 |

帖子详情页的面板里有「打开转帖列表 / 打开引用列表」按钮，直接跳到对应页面，不用自己拼地址。

**两种采集方式，随时切换**

- **手动滑动**（默认）：点开始后脚本不自己滚，你滑到哪记到哪，不停就一直记录
- **自动滑动**：点开始后自动向下滚动，滚到底且连续 3 次无新增时自动停止
- 抓取过程中可以点悬浮条上的 `⇅` 在图两种模式间切换，不用暂停重启
- 按推文 ID / 用户名去重；自动滚动的间隔带 ±25% 随机抖动，降低触发风控的概率

**复制与导出**

- **复制正文 + 评论**：详情页专用，输出 Markdown，主帖在上、评论按有序列表排列，跟评用缩进分层（最多 3 级）
- **复制 / 导出 Markdown**：适合直接粘进笔记
- **导出 JSON**：全字段，给程序用
- **导出 CSV**：带 BOM，Excel 直接打开不乱码

## 使用方法

1. 打开目标页面：用户主页、帖子详情、转帖列表或引用列表
2. 点右下角蓝色圆点展开面板（找不到就按 `Alt+X`）
3. 点「开始抓取」，面板自动收起，右下角出现小胶囊显示实时条数
4. 手动往下滑（或先在面板勾上「自动滚动」）
5. 滑到位置后点小胶囊上的 `❚❚` 暂停，面板会自动展开
6. 点「复制正文 + 评论」「复制 MD」，或导出 JSON / CSV

`Esc` 也能暂停。收藏的条数目标只作提示，不会中断记录。

## 抓取字段

**推文**：推文 ID、链接、作者昵称、账号、发布时间（ISO）、正文（emoji 保留）、回复 / 转帖 / 喜欢 / 书签 / 观看数、引用推文的正文与作者、图片与视频链接、卡片链接、转帖上下文（如「已置顶」「某某 转帖了」）、是否机器译文。

**用户**（转帖列表页）：账号、昵称、简介、关注关系提示。

## 说明与限制

- 只抓**已经渲染进 DOM** 的内容。X 是虚拟列表，滚出视口的节点会被回收，所以必须边滑边记；长评论区想抓全，先往下滑一段。
- 页面开了自动翻译时，抓到的正文是译文，会用「是否译文」字段标记出来；要原文请在 X 设置里关掉自动翻译。
- 抓取数据只存在内存里，刷新页面即清空；面板展开状态与设置项会记住。
- 除剪贴板外没有额外权限，不上报任何数据。
