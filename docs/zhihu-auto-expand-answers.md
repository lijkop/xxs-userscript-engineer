# 知乎自动展开全部回答

> 版本：1.0.1 · 作者：小小薯（XXS） · 反馈：[Telegram 频道](https://t.me/zzyyffxx)

## 简介

自动点击知乎问答页的「查看全部回答」，并且不触发页面滚动。

## 功能

- 检测到「查看全部回答」按钮即自动点击
- MutationObserver 监听 DOM，异步加载出来的按钮同样会被处理
- 不滚动页面，阅读位置不被打断

## 使用方法

安装后打开知乎问答页面即自动生效，无需操作。

## 配置说明

无需配置。脚本不读写本地存储。

## 兼容网站

- `*://*.zhihu.com/question/*`
