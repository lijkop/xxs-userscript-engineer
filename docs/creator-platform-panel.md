# 创作者跨平台管理面板

> 版本：2.0.1 · 作者：小小薯（XXS） · 反馈：[Telegram 频道](https://t.me/zzyyffxx)

## 简介

给跨平台创作者用的常驻导航面板，把各平台入口、标签与备注集中管理。

## 功能

- 常驻面板，支持边缘吸附，不遮挡页面内容
- 平台与标签下拉筛选，快速定位入口
- 每个入口可写备注
- 配置支持导入导出，换设备直接迁移

## 使用方法

1. 安装后面板出现在页面边缘
2. 快捷键 `Ctrl + Shift + M` 打开 / 关闭面板
3. 也可以通过油猴菜单「📡 打开/关闭创作者面板」切换
4. 在面板内添加平台入口、标签与备注

## 配置说明

- 面板内容保存在本地存储，可导出备份、导入恢复
- 数据不上传

## 兼容网站

- `*://*/*`（全站脚本：面板需要在任意页面常驻）
