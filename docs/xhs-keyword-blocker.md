# 小红书关键词屏蔽器

> 版本：1.0.1 · 作者：小小薯（XXS） · 反馈：[Telegram 频道](https://t.me/zzyyffxx)

## 简介

小红书网页版关键词屏蔽工具，提供可视化控制面板，适配无限滚动加载。

## 功能

- 自定义关键词，命中即拦截
- 两种拦截模式：完全隐藏 / 模糊处理
- 适配无限滚动，新加载的笔记同样生效
- 可视化面板管理关键词，数据持久化保存

## 使用方法

1. 安装后打开 xiaohongshu.com
2. 点击油猴菜单「⚙️ 打开屏蔽设置」
3. 添加关键词（输入后回车确认），选择拦截模式
4. 配置即时生效

## 配置说明

- 配置存储键：`xhs_blocker_config`
- 面板内维护关键词与拦截模式，数据保存在本地
