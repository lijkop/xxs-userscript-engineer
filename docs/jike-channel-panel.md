# 即刻分区快捷面板

> 版本：0.3.1 · 作者：小小薯（XXS） · 反馈：[Telegram 频道](https://t.me/zzyyffxx)

## 简介

在即刻网页版右下角添加常驻悬浮面板，用于收藏和快速跳转自定义分区。

## 功能

- 右下角常驻悬浮面板，随时可用
- 收藏多个自定义分区链接，一键跳转
- 支持在面板内增删改与排序

## 使用方法

1. 安装后打开 web.okjike.com
2. 展开右下角悬浮面板
3. 添加常逛的分区链接，点击即可跳转

## 配置说明

- 配置存储键：`jike_custom_links`
- 分区链接列表保存在本地，不上传
